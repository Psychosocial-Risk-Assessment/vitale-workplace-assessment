# Vitale Workplace Assessment

Plataforma web para aplicação de questionários de avaliação de riscos psicossociais, permitindo configurar empresas, coletar respostas de forma confidencial e apoiar a conformidade com a NR-1 por meio de instrumentos como HSE-IT Indoor, HSE-IT Outdoor e COPSOQ III.

## ✨ Funcionalidades

- Aplicação de questionários psicossociais
- Suporte ao HSE-IT Indoor
- Suporte ao HSE-IT Outdoor
- Suporte ao COPSOQ III
- Geração de links para colaboradores
- Coleta confidencial de respostas
- Integração com Google Forms
- Interface responsiva para desktop e dispositivos móveis

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript (ES6)
- Google Forms
- GitHub Pages
